# GitLab CI/CD Basic Pipeline

Thư mục này chứa cấu hình CI/CD cơ bản cho Bài 6.2.1:
- Tệp `.gitlab-ci.yml`: Định nghĩa 3 stages (`build`, `test`, `deploy`) và 4 jobs (`build-job`, `test-job1`, `test-job2`, `deploy-prod`).
- Mục đích: Làm quen với cú pháp YAML của GitLab CI, cách các stage thực thi tuần tự, cách các job cùng stage chạy song song, và cách xem log trong giao diện GitLab.
